# tests/eval/clips/

Drop video files here. Not tracked in git (too large) - a matching
ground truth file in `../ground_truth/` is what's committed instead.

Naming convention: `<condition>_<description>_<number>.mp4`, e.g.
`day_normal_01.mp4`, `night_jam_02.mp4`. `<condition>` is one of
`day`, `night`, `rain`, `jam`.

Full instructions (how to write the ground truth file, how to run the
harness, how to read the report): see `../README.md`.
